## 七、共性问题与建议

1. **启动与注入时序是最大故障源**：启动闪退、白屏、后端掉线、插件/脚本不加载多指向
   注入就绪前读取状态或单实例锁/旧进程残留。建议在启动链路补统一的就绪探测与超时提示，
   并把 `latest-status.json` 中的失败阶段做成用户可见诊断。
2. **切换供应商/模型时的配置覆盖仍未收口**：auth.json 认证态、MCP、沙盒、记忆设置、
   Windows Claude 配置等在多次修复后仍有零散缺口，建议把「用户托管配置保留」做成白名单式统一层，
   并补 `relay_config` 文本断言用例。
3. **Windows 特有问题占比高**：文件锁/拒绝访问、任务栏图标、更新器占用、PATH 与路径迁移，
   建议补 Windows 集成测试矩阵。
4. **不少 issue 长期停在旧版本**：信息不足的条目里有大量 1.1.x / 1.2.x 报告。建议先统一
   回复「请在 v1.10.0 复验」，再按新日志决定是否保留。
5. **插件市场与 Computer Use / 浏览器**：大量报告落在上游账号与运行时依赖上，
   本仓库能做的是把失败原因区分为「未登录 / 未开启兼容开关 / 上游不可用」，避免统一报成连接失败。
